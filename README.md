# Диплом-Чек AI

Проверка диплома нейросетью Groq: загружаете файл, нажимаете кнопку — через несколько
секунд документ появляется «на бумаге», ошибки подсвечены **красным**, недочёты —
**жёлтым**, а при наведении курсора на подсветку выезжает выноска с объяснением и
подсказкой, как исправить.

## Что внутри

| Файл | Назначение |
|---|---|
| `server.py` | Python-сервер: извлекает текст, проверяет, отдаёт API и страницу |
| `index.html` | Клиент: интерфейс, подсветка, выноски, диаграммы, фон с котиками |
| `selftest.py` | Автотест всего конвейера без браузера |
| `groq_key.txt` | (необязательно) ваш ключ Groq — создайте сами |

Внешних зависимостей нет — только стандартная библиотека Python 3.9+.

## Запуск

```powershell
cd C:\leonid\agentmame

# без ключа — работает локальный нормоконтроль (эвристики)
python server.py

# с ключом Groq (https://console.groq.com/keys)
$env:GROQ_API_KEY = "gsk_..."
python server.py
```

Откройте **http://127.0.0.1:8765**

Полезные ключи:

```powershell
python server.py --port 9000          # другой порт
python server.py --key gsk_xxxxx      # ключ прямо в командной строке
python server.py --host 0.0.0.0       # доступ из локальной сети
```

Ключ также можно положить в файл `groq_key.txt` рядом с `server.py` — сервер
подхватит его и перечитает при изменении.

## Что поддерживается

* **.docx** — читается напрямую из ZIP + XML, без python-docx;
* **.pdf** — через `pypdf`, если установлен, иначе грубое извлечение;
* **.txt / .md / .rtf / .csv** — обычный текст (кодировки utf-8, cp1251, koi8-r, cp866);
* **вставленный текст** — вставьте в поле слева и нажмите «Проверить вставленный текст»;
* drag & drop и вставка файла из буфера (Ctrl+V).

## Режимы

* **Нейросеть Groq** — модель выбирается в списке: Llama 3.3 70B (по умолчанию),
  Llama 3.1 8B, GPT-OSS 120B / 20B, Qwen3 32B. Текст режется на фрагменты по 6000
  символов, каждый уходит отдельным запросом.
* **Локальный нормоконтроль** — ~25 правил (пробелы, пунктуация, «в течении»,
  «не смотря на», повторы слов, канцелярит, длинные предложения, прямые кавычки
  и т. д.). Работает без ключа и без интернета.

Если ключ неверный, кончился лимит или пропала сеть — сервер **не падает**, а
показывает результат локальной проверки и пишет причину в блоке заметок.

## Как читать результат

* **Слева** — загрузка файла, выбор модели, кнопка проверки, прогресс.
* **В центре** — документ «на бумаге», разбитый на страницы. Подсветка:
  красная — ошибка, жёлтая — недочёт. Наведите курсор — выноска с категорией,
  цитатой, объяснением и пунктом «Как исправить». Номер в кружке — номер
  замечания, он же в списке справа.
* **Справа** — оценка (кольцо), счётчики, столбчатая диаграмма по категориям,
  фильтры «Все / Ошибки / Недочёты» и список замечаний. Клик по замечанию
  прокручивает документ к нужному месту и подсвечивает его.

Оценка: `100 − 5 × ошибки − 2 × недочёты`, но не ниже 5.

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | страница интерфейса |
| `GET` | `/api/health` | `{ok, has_key, models, default_model}` |
| `POST` | `/api/check` | тело — файл; заголовки `X-Filename-B64`, `X-Mode` (`ai`\|`local`), `X-Model`; возвращает `job_id` |
| `GET` | `/api/job?id=…` | `{status, progress, stage, result}` |

Проверка асинхронная: клиент опрашивает задачу и рисует прогресс.

## Проверка самого проекта

```powershell
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
python selftest.py
```

Тест прогоняет извлечение текста, локальный нормоконтроль, поиск позиций находок,
разбивку на страницы, сборку диаграммы и полный HTTP-цикл (`health` → `check` → `job`).

## Ограничения

* До 30 МБ на файл, до 400 замечаний в отчёте, до 8 фрагментов по 6000 символов
  уходит в нейросеть (очень длинный диплом проверяется частично — об этом будет
  заметка).
* PDF без текстового слоя (сканы) не распознаётся — нужен OCR.
* Сервер локальный, без авторизации: не выставляйте его в открытый интернет.
